# Responsive Landing Page — Full Stack Project

This repository contains `frontend/` and `backend/` directly under the project root.

## Run locally
1. Start MongoDB.
2. Terminal 1:
   ```powershell
   cd backend
   npm install
   Copy-Item .env.example .env
   npm run dev
   ```
3. Terminal 2: open `frontend/index.html` with VS Code Live Server.

Frontend normally runs at `http://127.0.0.1:5500`; backend at `http://localhost:5000`.
